##  Project Overview

This project demonstrates how **Apache Spark**, **PySpark**, and **Spark SQL** can be used to efficiently process and analyze large-scale Apache Web Server log files.

The analysis focuses on identifying web traffic patterns, unique visitors, HTTP response statistics, and frequently requested resources while showcasing the power of distributed data processing.

This project is designed to demonstrate practical **Big Data Engineering**, **Data Analytics**, and **Cloud Data Processing** skills using Apache Spark.

---

##  Business Problem

A US-based organization wants to analyze its Apache Web Server logs to better understand user access patterns and evaluate whether improvements are needed in its application deployment strategy.

Since the log files contain millions of records stored in compressed **.gz** format, traditional processing techniques are inefficient.

Apache Spark provides scalable distributed processing capable of analyzing these large datasets efficiently.

---

## 📂 Dataset

The project uses two Apache Web Server log files in **Common Log Format (CLF)**.

```
Access_log_Jul1995.gz
Access_log_Aug1995.gz
```

Each log record contains:

- Host Name
- Timestamp
- HTTP Request
- Response Code
- Response Size

Example

```text
199.72.81.55 - - [01/Jul/1995:00:00:01 -0400]
"GET /history/apollo/ HTTP/1.0"
200 6245
```

#  Data Wrangling

Before analysis, the raw Apache logs were transformed into a structured dataset.

### Steps Performed

- Parsed Apache Common Log Format using Regular Expressions
- Removed malformed records
- Converted timestamps into Spark Timestamp format
- Converted response codes into Integer
- Replaced missing byte values ("-") with zero
- Extracted endpoint information from HTTP requests
- Created temporary Spark SQL views

#  Sample Spark SQL

```sql
SELECT
COUNT(DISTINCT host)
FROM logs;
```

# Sample PySpark

```python
logs.filter(col("status")==404) \
.groupBy("endpoint") \
.count() \
.orderBy(desc("count")) \
.limit(15)
```
